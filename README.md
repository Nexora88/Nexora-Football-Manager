# ⚽ Nexora Football Manager

> **A next-generation football management simulation built for the Turkish football experience.**

**Nexora Football Manager** is an ambitious football-management game combining deep club management with a live match experience. The long-term goal is to let the player build a club from the lower leagues, shape its identity, manage transfers and finances, develop young players, make tactical decisions and experience matches as they unfold.

## 🎮 Vision

This project is designed around one principle:

**You don't just manage a team. You build a football club.**

The game aims to combine:

- 🏟️ Club and board management
- 🧠 Tactical planning and live tactical changes
- 🔄 Transfers, contracts and squad building
- 🌱 Youth academy and player development
- 💰 Budgets, wages, sponsors and club finances
- 👥 Fans, morale, pressure and reputation
- 📊 Player and team analytics
- ⚽ Live match simulation with event-driven gameplay
- 🏆 Leagues, cups, seasons and long-term career progression
- 🎬 Match highlights and cinematic moments as the project evolves

## 🛠️ Current Technology Direction

The prototype starts lightweight so the game engine can be developed before adding unnecessary infrastructure.

- **HTML / CSS / JavaScript** — initial playable shell
- **Canvas / SVG** — planned match visualisation
- **JSON / TypeScript data models** — planned game data layer
- **Backend/database** — to be introduced when persistent saves and online features require it

The architecture can later evolve into a larger TypeScript/React-based application without throwing away the core simulation concepts.

## ⚠️ Project & Asset Policy

The public prototype will use original or appropriately licensed assets. Real club names, logos, player likenesses, photographs and other protected material should only be used when the necessary rights or licences are available.
